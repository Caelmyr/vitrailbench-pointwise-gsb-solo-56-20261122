# Vitrail Bench

Vitrail Bench is a local image workbench for backlit window and stained-glass panels. Load a marked synthetic specimen from the collection, or create a panel with measured dimensions. Camera originals and settings stay in a local volume.

Run `./start.sh` or `BUILDX_BUILDER=default docker compose up -d --build --wait`. The default address is `http://127.0.0.1:19961`. Set `VITRAIL_PORT` for a free local port. Stop with `docker compose stop`. The Compose volume retains panels, source photographs, physical marks and saved reports when the web container is replaced. Local development uses Python 3.11, `python -m pip install -r requirements.txt` and `python -m vitrail`.

Select a capture before drawing four ordered camera corners for panel alignment. Choose and run an inspection from the right-hand controls. The image stage switches between the source and the selected derived view. Capture ticks select input order in workbench state. Light and color tools read registered transmission, density, exposure, named color patches and edge illumination. The flat-field correction pairs a glass capture with an open-backlight capture: it divides the glass by the smooth illumination field, shows the original and corrected transmission side by side, and maps which pixels were borrowed from a neighbouring flat reading. Filling a small isolated hole, an extended gap and an elongated strip each carry their own lower confidence, and anything beyond the borrow limit stays uncorrected. Construction tools inspect lead and solder paths, catalog pane interiors and measure a drawn gauge or visible line. Surface tools inspect texture, optical ridges, marks, local gloss, and appearance changes. Camera tools report conditions such as coverage, clipping and local sampling. Surveys store physical marks. Data and available PNG or CSV files are displayed with the observations. Retain a preview to reopen it from Records and export an evidence ZIP or inspection PDF; a retained flat-field correction also rebuilds its corrected preview from the recorded settings without rewriting any source photograph.

Use PNG, TIFF, JPEG or WebP, one frame per file. Tagged camera colors are converted to sRGB. Lossless high-bit input is accepted for grayscale only. The workspace keeps an original byte checksum separate from the computed view. Captures allow up to 28 MB or 16 million pixels each, with at most 34 million decoded pixels across a workbench request. Regions are normalized coordinates in the registered panel plane. Physical values rely on the dimensions and actual camera sampling. No result has a certified instrument calibration. Missing source support, saturation and low contrast limit what a report can establish. All provided specimen images and measurements are synthetic examples.
