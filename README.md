# Vitrail Bench

Vitrail Bench is a local image workbench for backlit window and stained-glass panels. Load a marked synthetic specimen from the collection, or create a panel with measured dimensions. Camera originals and settings stay in a local volume.

Run `./start.sh` or `BUILDX_BUILDER=default docker compose up -d --build --wait`. The default address is `http://127.0.0.1:19961`. Set `VITRAIL_PORT` for a free local port. Stop with `docker compose stop`. The Compose volume retains panels, source photographs, physical marks and saved reports when the web container is replaced. Local development uses Python 3.11, `python -m pip install -r requirements.txt` and `python -m vitrail`.

Select a capture before drawing four ordered camera corners for panel alignment. Choose and run an inspection from the right-hand controls. The image stage switches between the source and the selected derived view. Capture ticks select input order in workbench state. Light and color tools read registered transmission, density, exposure, named color patches and edge illumination. The **Replacement glass sample matching** inspection takes two captures of the same laid-out pieces (daytime white lamp and evening warm lamp), each showing the surviving fragment, three replacement samples and one clear blank. Mark the five piece interiors on each photo: the blank balances the lamp color, samples are ranked by CIELAB hue separately per light, and the brightness (delta L) gap is reported and flagged on its own. When the two lights produce different orders, no single first choice is invented. Retain the inspection and export the selection sheet PDF, which gives one printable page per lamp with the actually measured patch boxes, the per-sample ranking and the flags, for on-site checking. Construction tools inspect lead and solder paths, catalog pane interiors and measure a drawn gauge or visible line. Surface tools inspect texture, optical ridges, marks, local gloss, and appearance changes. Camera tools report conditions such as coverage, clipping and local sampling. Surveys store physical marks. Data and available PNG or CSV files are displayed with the observations. Retain a preview to reopen it from Records and export an evidence ZIP or inspection PDF.

Use PNG, TIFF, JPEG or WebP, one frame per file. Tagged camera colors are converted to sRGB. Lossless high-bit input is accepted for grayscale only. The workspace keeps an original byte checksum separate from the computed view. Captures allow up to 28 MB or 16 million pixels each, with at most 34 million decoded pixels across a workbench request. Regions are normalized coordinates in the registered panel plane. Physical values rely on the dimensions and actual camera sampling. No result has a certified instrument calibration. Missing source support, saturation and low contrast limit what a report can establish. All provided specimen images and measurements are synthetic examples.
